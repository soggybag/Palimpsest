Palimpsest — Web Controller

Sends real MIDI to the Daisy over USB, using the same notes/CCs as docs/testing.md. Requires Chrome or Edge (Web MIDI) — Safari and Firefox don't support it. Not a live view of the hardware: knob positions and button lights are this page's own local state, not read back from the module.
